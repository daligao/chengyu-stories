## What is this?

Every 成语 (chengyu) is a 4-character idiom with a story behind it — usually from ancient China, 2,000+ years old. They appear constantly in modern Chinese writing, news, and conversation. If you're studying for HSK5–6, you'll need them.

This tool makes them memorable by telling the actual story, then testing whether you can use them in a modern context.

## How it works

For each chengyu:

1. **Read the origin story in Chinese** — 2,000+ years old, 150–250 characters
2. **Click any highlighted word** → instant pinyin + meaning popup
3. **Read the English translation** to confirm understanding
4. **See modern usage** — 2 example sentences (Chinese + English)
5. **Take the usage quiz** — given a real scenario, pick the right chengyu from 4 options

Progress is saved in your browser.
